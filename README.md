# LocalControl

Демо веб-панели системы управления умными замками TTLock через флот шлюзов ESP32 — локально, без обязательной зависимости от облака производителя.

## Что это

LocalControl — система управления доступом на базе TTLock-замков: BLE-шлюзы на ESP32 общаются с замками локально, сервер даёт единую панель управления, уведомления и журнал доступа.

**Сейчас в этом репозитории — только фронтенд-демо панели** (`Localcontrol_demo.html`), без бэкенда и прошивки. Показывает интерфейс: список замков и шлюзов, управление доступом, журнал событий.

## Возможности (в демо-версии)

- Просмотр и управление замками и шлюзами в едином интерфейсе
- Журнал событий доступа
- Адаптивный UI (desktop/mobile)

## Запуск демо

Открыть `Localcontrol_demo.html` в браузере — статический файл, backend не требуется.

## Статус

Ранняя стадия, активная разработка. Backend и прошивка — в приватной части проекта.
